# 平台规范参考

定稿导出时读取。下面是常用起点，平台模板会更新：动手前打开对应官方模板或文档核对，以官方当前版本为准，并在品牌 README 写明核对日期。

## macOS 应用图标

- 1024 × 1024 透明画布；主体为 824 × 824 的连续曲率圆角方块（超椭圆，n≈5 是常用近似），居中，四边各留 100px 透明边距。
- 主体形状和阴影由图标自己画，系统不会替你加遮罩。
- 导出 16、32、64、128、256、512、1024px；小尺寸从 1024 高质量缩小（如 Lanczos），必要时为 16/32 单独做光学调整。
- 标志在主体内略高于几何中心时视觉上更稳；具体高度和中心由所有者在预览里确认后写进规范。

## macOS 菜单栏图标

- 用 template 图：只有黑色和透明，系统按菜单栏明暗自动着色。
- 画布常用 18 × 18pt（@1x 18px，@2x 36px），标志高约 16pt；菜单栏图标显得小时，先检查标志实际占画布的高度，宽而扁的形状容易只占一半高度。
- 只靠剪影识别：眼睛、瞳孔等细节在 16pt 下要么清晰，要么去掉。
- 预览要在浅色和深色菜单栏背景下各看一份 1x 和 2x。

## iOS / iPadOS

- 提供 1024 × 1024 不透明方形图，系统负责圆角遮罩；不要自己画圆角或留透明边。
- 新系统支持深色和着色变体时，按官方模板另出版本。

## Android

- 自适应图标：108 × 108dp 画布，分前景层和背景层；外圈会被各厂商遮罩裁掉，标志放在中心直径约 66dp 的安全区内。
- 单色主题图标：另出一份单色前景层。
- Play 商店图标：512 × 512 PNG。

## Web 与 PWA

标志在网站里主要以两种形态出现：页头的横版组合标（符号加字标），以及单独的符号（favicon、PWA 安装图标、社交分享图）。

- **组合标**：横版为主，必要时加竖版；SVG 交付。页头高度通常 24–32px，在这个高度下检查字标可读、符号和字标的间距与基线对齐。浅色和深色主题各一版，或用 `currentColor` 让页面控制颜色。
- **favicon**：`favicon.svg` 可在 SVG 内用 `@media (prefers-color-scheme: dark)` 适配深色标签栏；另给 32px 的 PNG 或 ICO 兜底。16px 下只靠剪影识别：负形缝隙在 16px 下至少要有 1px（即 1024 画布上约 64 单位），否则交叠层次会糊掉；做不到就单独出简化的小尺寸版本，去掉缝隙或减少交叠。
- **PWA 安装图标**：在 Web App Manifest 中提供 192 × 192 和 512 × 512 PNG（`purpose: any`），再提供 512 × 512 的 maskable 版本（`purpose: maskable`）：满版底色，标志放在中心直径约为边长 80% 的圆形安全区内，四周会被系统裁成圆形、圆角方形等形状。
- **iOS 主屏**：PWA 在 iOS 上添加到主屏时使用 `apple-touch-icon`（180 × 180，不透明满版）。即使不做原生移动端，也建议提供这一张。
- **社交分享图**（可选）：`og:image` 常用 1200 × 630，放组合标和一句定位。
- 需要单独检查：浏览器标签页（浅色和深色）、书签栏、PWA 安装后的桌面或启动器图标。

## 通用检查

- 主色版、单色墨色版、反白版。
- 浅色、深色背景各看一遍。
- 最小尺寸下仍能靠剪影认出。
